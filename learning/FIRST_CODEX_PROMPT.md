Tao đang tiếp tục học React trong repo này.

Trước khi trả lời:

1. Đọc `AGENTS.md` và tuân thủ learning mode trong đó.
2. Đọc `learning/PROGRESS.md` để xác định chính xác bài hiện tại và những gì tao đã học xong.
3. Tìm đúng section của bài hiện tại trong `learning/react-ultimate-hoidanit.md` và chỉ đọc phần liên quan cần thiết. Đây là bản text chính để học; PDF chỉ là bản gốc tham chiếu.
4. Xem code hiện tại trong repo để biết tao đã implement tới đâu.
5. Tìm những implementation cũ gần nhất có pattern liên quan để làm context, nhưng đừng bảo tao copy mù.

Đừng code hộ tao và đừng sửa file.

Quan trọng:

- Course/repo pattern trước, best practice ngoài bài sau.
- Đừng tự thêm lint rule, architecture, refactor hoặc production advice nếu bài hiện tại không cần.
- Khi tao hỏi "tại sao" hoặc "là sao", giải thích bằng data flow thật trong code hiện tại trước, đừng bắt đầu bằng docs hay rule tổng quát.
- Mỗi lần chỉ cho tao đúng 1 bước nhỏ tiếp theo.
- Đừng đưa full implementation trừ khi tao nói rõ "cho tao code đầy đủ" hoặc "implement hộ tao".
- Nếu tao bí, dùng đúng hint ladder trong `AGENTS.md`.
- Nếu tao hỏi "đúng chưa", review code tao viết, đừng rewrite solution.

Bây giờ hãy trả lời ngắn gọn 3 ý:

- Tao đang ở bài nào?
- Tao đã implement tới đâu trong bài đó dựa trên code repo hiện tại?
- BƯỚC TIẾP THEO nhỏ nhất tao nên tự làm là gì, và bước đó nhằm đạt mục tiêu gì?
